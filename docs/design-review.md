# Design review – CD Bund alignment register

Standing register for design reviews of the BBL Mieterportal prototype against the Swiss Confederation design system (CD Bund). Later review rounds append to the rounds table and extend the findings tables; finding IDs are stable and never reused.

## 1. Purpose and scope

Reviewed: every route and recurring UI pattern of the prototype, at the design system’s breakpoints plus 320/360/390 px including touch emulation; the CSS architecture; accessibility (WCAG 2.1 AA); CD formal elements and editorial conventions.

Excluded: JS application logic beyond what styling and semantics require; the Python utilities under `scripts/data` and `scripts/research`; content correctness of the mock data. `docs/CD-GAP-ANALYSIS.md` (round 1) was deliberately not used as an input – this round was done with fresh eyes; see section 7 of the review brief and the reconciliation notes in the changelog for its disposition.

Normative reference: the local clone of [swiss/designsystem](https://github.com/swiss/designsystem) at git tag **v1.0.45** (HEAD `5f03f257`). The clone’s `package.json` version field (1.0.5) is stale upstream and not meaningful. The README’s claimed v1.0.9 does not match this reference; zero findings were attributable to drift between those versions – the deviations are implementation-side. Where behaviour could not be verified against the clone or the hosted Storybook, the finding is marked UNVERIFIED rather than asserted.

Method: computed-value comparison, not visual estimation. A Playwright harness (`scripts/review/capture-baseline.mjs`) captures every route at 12 viewport configurations and dumps per-element computed-style hashes, full computed styles for a probe set, and full-page screenshots. Nine specialised review passes (tokens, colour, typography, spacing, responsive/mobile, states, accessibility, CSS quality, CD formal/editorial) ran against the shared evidence contract, followed by a component sweep over 73 surfaces at 1280 px and 360 px. Same-root-cause reports were merged at consolidation (28 merges); the register lists root causes, with symptoms as affected locations.

Tolerances: colours, tokens, font families, weights and type sizes must match exactly; computed layout values deriving from different DOM structure than the design system’s own markup carry a 1 px tolerance below which nothing is logged.

Verdicts (section 5): `Aligned` = no open findings above P3; `Minor deviations` = open P3 only; `Major deviations` = any open P1/P2; `No DS equivalent` = nothing comparable exists in the design system – the comparison basis actually used is stated.

## 3. Summary

218 findings: 4 P1, 45 P2, 102 P3, 67 P4 – from nine specialised review passes (150 raw findings), a 73-component sweep (95 raw findings), and one reviewer-added finding; 28 same-root-cause reports were merged into their primaries. Priorities are severity only: P1 blocks users or violates the CD visibly, P2 is a clear DS deviation, P3 consistency/maintainability, P4 cosmetic.

The ten most important findings:

| # | ID | Finding |
| --- | --- | --- |
| 1 | A11Y-001 | Clickable table rows (inbox, queue, floors, related applications) have no keyboard access – a core task is blocked for keyboard users |
| 2 | STA-001 | The queue’s keyboard handler stays armed on every later route and hijacks Enter and arrow keys app-wide |
| 3 | COL-001 | Every data table drifts from the DS blue-gray scheme; header rows fail WCAG AA contrast |
| 4 | RWD-001 | Two tables render without a scroll wrapper and silently clip columns on phones (WCAG 1.4.10 content loss) |
| 5 | A11Y-005 | The `main` landmark is empty on every route – all content sits outside it |
| 6 | A11Y-006 | Route changes never update the document title or move focus – every page announces «BBL Mieterportal» |
| 7 | CD-003 | Switching to FR/IT/EN leaves roughly 45 chrome strings German – half-translated federal chrome |
| 8 | CSS-002 | An unscoped print block strips the Confederation branding from every printed page |
| 9 | TYP-002 + SPC-002 + COL-001 | The table family deviates on three axes at once – type size, cell density and colour – across the most-used admin surfaces |
| 10 | CD-001 | The language switcher orders the official languages wrongly (RM last, absent on mobile) |

Overall assessment: the portal’s federal chrome, token base and component inventory are recognisably and substantially CD Bund – and the deviations are systematic rather than random. They concentrate in (a) the data-table family, deviating on colour, type size and density simultaneously, (b) keyboard and assistive-technology support beneath a visually polished surface (4 P1 + 45 P2 overall, the majority accessibility-related), and (c) editorial completeness outside German. The README’s claim of ≈ 99 % alignment with WCAG AA verified is not defensible against this register. The honest statement is the component matrix in section 5: of 73 assessed surfaces, at desktop 2 are Aligned, 31 show minor deviations, 28 show major deviations and 12 have no DS equivalent; at 360 px the split is 1 / 28 / 32 / 12. The README is corrected accordingly in the reconciliation.
